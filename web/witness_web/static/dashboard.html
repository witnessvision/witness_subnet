Evaluation policy
  • No king: 100% burn
  • King: 30% king · 70% burn
  • First king needs 2 valid submissions
  • Window = 2 epochs
  • Each evaluator samples 5 videos × 2 clips from 1,000
  • 2 Luna references per clip
  • King and challengers share the same batch
  • 60 s answer limit per clip
  • One 90% futility check after 3 videos, for this batch only
  • Early stops publish upper bounds and never crown
  • Clip detail revealed only after the window closes
  • reward = quality × (0.8 + 0.2 × time_score)
